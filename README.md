# 🏢 ระบบจองห้องประชุมภายในองค์กร (Meeting Room Booking System)

เว็บแอปพลิเคชันระบบจองห้องประชุม ออกแบบและพัฒนาเพื่อใช้งานภายในองค์กรโดยเฉพาะ รองรับการรันบนระบบ Local (เครื่องคอมพิวเตอร์แม่ข่ายหรือเครื่องใดเครื่องหนึ่งในออฟฟิศ) และให้อุปกรณ์ทุกชนิดในเครือข่าย Wi-Fi / Local Area Network (LAN) เดียวกันสามารถเข้าใช้งานได้ทันที

---

## 🌟 จุดเด่นและคุณสมบัติเด่นของระบบ

1. **ใช้งานได้ทุกอุปกรณ์ (Cross-Device Responsive)**:
   - **คอมพิวเตอร์และแล็ปท็อป (Desktop/Laptop)**: หน้าจอแบ่งคอลัมน์กว้างชัดเจน มีฟอร์มสร้างการจองและตารางเวลาไทม์ไลน์
   - **สมาร์ตโฟน (iOS / Android)**: มีแถบเมนูนำทางด้านล่าง (Bottom Navigation Bar) ใช้งานด้วยนิ้วโป้งถนัดมือ
   - **แท็บเล็ต / จอหน้าห้องประชุม (Room Display Kiosk Screen)**: หน้าจอเต็มสำหรับวางหน้าห้องประชุม บอกสถานะห้องว่าง (สีเขียว) หรือกำลังประชุม (สีแดง) พร้อมปุ่มจองด่วน 15, 30, 60 นาที
2. **ระบบรัน Local Network พร้อม QR Code ในตัว**:
   - เปิดระบบครั้งเดียว เครื่องอื่นๆ ในวง Wi-Fi เดียวกัน สแกน QR Code เพื่อเปิดเว็บได้ทันที ไม่ต้องจำหรือพิมพ์ IP Address
3. **ป้องกันการจองเวลาทับซ้อน (Overlap Conflict Detection)**:
   - ตรวจสอบการชนกันของเวลาในระดับนาที พร้อมแจ้งเตือนว่าชนกับหัวข้อใด ผู้จองคนใด และช่วงเวลาใด
4. **มุมมองการแสดงผล 3 รูปแบบ**:
   - **Timeline Grid View**: แถบเวลาชั่วโมงต่อชั่วโมง 08:00 - 20:00 น. คลิกช่องว่างเพื่อจองได้ทันที
   - **Card / List View**: รายการการจองทั้งหมด พร้อมตัวกรองตามห้องและวันที่
   - **Live Room Cards**: การ์ดแสดงสถานะสดและอุปกรณ์ประจำห้อง
5. **ระบบความปลอดภัยและการยกเลิก (PIN Protection)**:
   - ผู้จองกำหนดรหัส PIN 4 หลักตอนจอง เพื่อใช้ยกเลิกการจองของตนเอง ป้องกันคนอื่นกดลบข้อมูล
   - มี **Master Admin PIN** สำหรับผู้ดูแลระบบ
6. **ระบบจัดการห้องประชุมและสิ่งอำนวยความสะดวก (Admin Console)**:
   - เพิ่ม แก้ไข ลบห้องประชุม กำหนดความจุคน, ชั้นที่ตั้ง, สีประจำห้อง, และอุปกรณ์ (Smart TV, ไมค์ลอย, Video Conference, Whiteboard, Wi-Fi)
7. **ส่งออกรายงาน (Export CSV/Excel)**:
   - ส่งออกข้อมูลเป็นไฟล์ Excel/CSV รองรับภาษาไทย (UTF-8 with BOM) สมบูรณ์แบบ
8. **ฐานข้อมูลถาวร (Persistent SQLite Database)**:
   - จัดเก็บข้อมูลลงไฟล์ `data/meeting_rooms.db` ผ่าน Built-in SQLite ปิดเปิดเครื่องใหม่ข้อมูลไม่สูญหาย

## 🚀 วิธีการเริ่มต้นใช้งาน (Quick Start)

### วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานบน Windows
1. เปิดโฟลเดอร์โครงการ `meeting-room-system`
2. ดับเบิลคลิกที่ไฟล์ **`run.bat`**
3. ระบบจะรัน Local Server และเปิดหน้าเว็บเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:3000`

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
cd meeting-room-system
node server.js
```

---

## 📱 การเข้าใช้งานจากอุปกรณ์อื่นในออฟฟิศ (Mobile / Tablet)
1. ตรวจสอบให้สมาร์ตโฟนหรือแท็บเล็ตเชื่อมต่อ Wi-Fi เดียวกันกับเครื่องคอมพิวเตอร์ที่รันระบบ
2. กดปุ่ม **"📱 สแกนเข้ามือถือ"** ที่แถบเมนูด้านบนของหน้าเว็บ
3. เปิดกล้องบนมือถือแล้วสแกน QR Code เพื่อเข้าใช้งานได้ทันที หรือพิมพ์ URL เช่น:
   ```
   http://192.168.x.x:3000
   ```

---

## 🔑 รหัสผ่านสำหรับผู้ดูแลระบบ
- **Master Admin PIN**: กำหนดผ่านตัวแปรสภาพแวดล้อม `ADMIN_PIN` หรือตั้งค่าในระบบ
- ใช้สำหรับ: ปลดล็อกหน้า **⚙️ จัดการ (Admin Console)**, เพิ่ม/ลบห้องประชุม, และยกเลิกรายการจองของพนักงานในกรณีฉุกเฉิน
