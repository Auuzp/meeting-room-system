🏢 คู่มือระบบจองห้องประชุมภายในองค์กร

ระบบ Meeting Room Booking Web Application (รองรับการรัน Local + ให้อุปกรณ์ภายนอกล็อกอินเข้าใช้งานได้)

บทที่ 1: การเปิดใช้งานระบบ (เลือกได้ 2 รูปแบบ)

ระบบสามารถรันได้ 2 โหมดตามความต้องการขององค์กร:

โหมดที่ 1: รันใช้งานเฉพาะในออฟฟิศ (Local Wi-Fi Only)

  • เหมาะสำหรับ: ใช้งานเฉพาะพนักงานที่ต่อสายแลนหรือ Wi-Fi ของออฟฟิศ
  • วิธีเปิด: ดับเบิลคลิกไฟล์ START-SYSTEM.bat
  • เข้าใช้งานผ่าน: http://localhost:3000 หรือ http://<IP-เครื่องโฮสต์>:3000

โหมดที่ 2: รัน Local แต่เปิดให้คนภายนอก/เน็ตมือถือ 4G/5G/WFH เข้าใช้งานได้ด้วย ⭐ [แนะนำ]

  • เหมาะสำหรับ: พนักงานที่อยู่นอกออฟฟิศ, ผู้บริหารที่ออกไปพบลูกค้า, พนักงาน Work From Home หรือใช้เน็ตมือถือ
  • วิธีเปิด: ดับเบิลคลิกไฟล์ START-ONLINE.bat
  • สิ่งที่ระบบทำให้อัตโนมัติ:
    1. รัน Local Web Server และฐานข้อมูล SQLite บนเครื่องคอมพิวเตอร์ของคุณ (ข้อมูลอยู่ในเครื่อง 100%)
    2. เชื่อมต่อระบบความปลอดภัย Cloudflare Secure Tunnel อัตโนมัติ (ไม่ต้องตั้งค่า Router)
    3. สร้างลิงก์ Public Internet URL (HTTPS ปลอดภัย) เช่น: https://xxxx.trycloudflare.com
    4. แสดงภาพ QR Code ให้พนักงานที่อยู่นอกออฟฟิศใช้กล้องมือถือสแกนเข้าใช้ได้ทันทีจากทุกที่ทั่วโลก!
💡 การปิดระบบ: ดับเบิลคลิกที่ไฟล์ STOP-SYSTEM.bat หรือปิดหน้าต่าง Command Prompt ได้ทันที

บทที่ 2: การเข้าใช้งานจากอุปกรณ์ต่างๆ

2.1 ผ่านคอมพิวเตอร์ในออฟฟิศ (Wi-Fi องค์กร)

เปิดเว็บเบราว์เซอร์เข้าที่: http://<IP-เครื่องโฮสต์>:3000 (เช่น http://192.168.1.50:3000)

2.2 ผ่านมือถือ (สมาร์ตโฟนเน็ต 4G/5G หรืออยู่นอกออฟฟิศ)

  1. ที่หน้าจอคอมพิวเตอร์ กดปุ่ม "📱 มือถือ" บนแถบเมนูด้านบน
  2. เลือกแท็บ "🌐 นอกออฟฟิศ (4G/5G/WFH)"
  3. ใช้กล้องมือถือสแกนภาพ QR Code หรือคัดลอกลิงก์ส่งเข้ากลุ่ม LINE บริษัท ให้พนักงานเปิดเข้าใช้ได้ทันที

2.3 โหมดจอแท็บเล็ตติดหน้าห้องประชุม (Room Display Kiosk)

นำ iPad หรือแท็บเล็ตไปติดไว้หน้าห้องประชุม แล้วเปิดไปที่: http://<IP-เครื่องโฮสต์>:3000/kiosk.html หน้าจอจะแสดงสถานะสีเขียว (ว่าง) / สีแดง (กำลังประชุม) พร้อมปุ่มจองด่วน 15, 30, 60 นาที

บทที่ 3: คู่มือสำหรับพนักงานทั่วไป

3.1 การยืนยันตัวตนพนักงาน (Employee Verification)

แม้จะเปิดให้เข้าจากภายนอกได้ แต่ เฉพาะพนักงานที่มีสิทธิ์ของบริษัทเท่านั้นที่จองได้

  • กดปุ่ม "เข้าสู่ระบบ" มุมขวาบน แล้วกรอก รหัสพนักงาน (เช่น EMP101) หรือพิมพ์ค้นหาชื่อตนเอง
  • เมื่อเข้าสู่ระบบแล้ว ชื่อผู้จองและแผนกจะถูกนำไปกรอกลงฟอร์มให้อัตโนมัติ

3.2 ขั้นตอนการจองห้องประชุม

  1. กดปุ่มสีส้ม "+ จองห้องประชุมใหม่" (หรือกด "จองห้องนี้" จากการ์ดห้องประชุม)
  2. เลือก ห้องประชุม ที่ต้องการใช้งาน (ห้อง A, B, C, D)
  3. เลือก วันที่ และ เวลาเริ่มต้น - สิ้นสุด (เช่น 13:00 - 14:30 น.)
  4. กรอกหัวข้อการประชุม และรหัส PIN 4 หลัก (ค่าเริ่มต้น 1234 หรือตั้งเองได้)
  5. กดปุ่ม "ยืนยันการจองห้อง"
🚨 การป้องกันการจองซ้ำ:
หากมีคนจองห้อง A เวลา 13.00 น. ไว้แล้ว คนอื่นที่พยายามเข้ามาจองห้องเดียวกันในเวลาดังกล่าว จะไม่สามารถจองซ้ำได้เด็ดขาด ระบบจะปฏิเสธทันทีพร้อมแจ้งเตือนชื่อคนจองเดิมและช่วงเวลาที่ติดจอง

3.3 การยกเลิกการจอง

ไปที่ตารางการจอง กดปุ่ม "ยกเลิก" ที่รายการของตนเอง และกรอกรหัส PIN 4 หลักที่ตั้งไว้ตอนจอง

บทที่ 4: คู่มือสำหรับผู้ดูแลระบบ (Admin Console)

เข้าสู่ระบบจัดการได้ที่: /admin.html หรือกดปุ่ม "⚙️ Admin" บนแถบเมนู (รหัส Admin PIN: 8888)

  • กำหนดห้องประชุม: เพิ่มห้องใหม่, แก้ไขชื่อห้อง, กำหนดความจุ, สถานที่ตั้ง, และอุปกรณ์ประจำห้อง
  • กำหนดสิทธิ์พนักงาน: เพิ่มรายชื่อพนักงานที่มีสิทธิ์ใช้, กดปุ่ม ⛔ ระงับ เพื่อระงับสิทธิ์ชั่วคราว, หรือกด ✅ เปิดสิทธิ์ เพื่อคืนสิทธิ์ให้พนักงาน
  • ส่งออกรายงาน: กดปุ่ม "📥 ส่งออก Excel" เพื่อดาวน์โหลดไฟล์สรุปการจองเป็นภาษาไทยเปิดใน Excel ได้ทันที

บทที่ 5: ความปลอดภัยและการตั้งค่าโดเมนบริษัท

5.1 ความปลอดภัยของระบบ

  • ไม่มีการเปิด Port ใน Router: จึงปลอดภัยจากการถูกเจาะระบบจากแฮกเกอร์บนอินเทอร์เน็ต
  • เข้ารหัสแบบ HTTPS: ปลอดภัย มีใบรับรอง SSL มาตรฐานสากล
  • ข้อมูลเก็บอยู่ที่เครื่องของคุณ 100%: ฐานข้อมูล SQLite อยู่บนเครื่องของคุณ ไม่ถูกส่งไปเก็บบนคลาวด์ภายนอก

5.2 การใช้ชื่อโดเมนถาวรของบริษัท (เช่น meeting.mycompany.com)

หากองค์กรมีชื่อโดเมนอยู่แล้ว สามารถเชื่อมต่อ Cloudflare Tunnel กับโดเมนของบริษัทได้ฟรี พนักงานจะสามารถเข้าใช้งานผ่าน https://meeting.mycompany.com ได้ตลอดเวลาโดยชื่อ URL ไม่เปลี่ยน!
