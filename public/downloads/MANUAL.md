## บทที่ 1: การเปิดใช้งานระบบ

### 1.1 สิ่งที่ต้องเตรียมบนเครื่องคอมพิวเตอร์แม่ข่าย (Host)
- **ระบบปฏิบัติการ:** Windows 10, Windows 11 หรือ Windows Server
- **โปรแกรมที่ต้องติดตั้ง:** Node.js (เวอร์ชัน 18 ขึ้นไป หรือ LTS ล่าสุด)
  - ดาวน์โหลดติดตั้งได้ฟรีที่: [https://nodejs.org](https://nodejs.org) (กด Next ติดตั้งตามปกติ)

### 1.2 วิธีการเปิดระบบ (เลือกได้ 2 โหมดตามการใช้งาน)

#### โหมดที่ 1: เปิดใช้งานเฉพาะภายในออฟฟิศ (Local Wi-Fi Only)
- เหมาะสำหรับ: ใช้งานเฉพาะพนักงานที่ต่อ Wi-Fi ในออฟฟิศ
- **วิธีเปิด:** ดับเบิลคลิกไฟล์ **`START-SYSTEM.bat`**
- เข้าใช้งานผ่าน: `http://localhost:3000` หรือ `http://192.168.x.x:3000`

#### โหมดที่ 2: เปิดให้คนภายนอก/เน็ตมือถือ 4G/5G/WFH เข้าใช้งานได้ด้วย (Online Access) ⭐ [แนะนำ]
- เหมาะสำหรับ: พนักงานที่อยู่นอกออฟฟิศ, ผู้บริหารที่ออกไปพบลูกค้า, พนักงาน Work From Home หรือใช้เน็ตมือถือ
- **วิธีเปิด:** ดับเบิลคลิกไฟล์ **`START-ONLINE.bat`**
- **สิ่งที่ระบบทำให้อัตโนมัติ:**
  1. รัน Local Web Server และฐานข้อมูล SQLite บนเครื่องคอมพิวเตอร์ของคุณ
  2. เชื่อมต่อระบบรักษาความปลอดภัย **Cloudflare Secure Tunnel** ให้อัตโนมัติ
  3. ระบบจะสร้าง **Public Internet URL (HTTPS)** ให้ทันที เช่น:  
     `https://xxxx.trycloudflare.com`
  4. แสดงภาพ QR Code ในหน้าต่างสีดำ และบนหน้าเว็บ ให้พนักงานภายนอกสแกนเข้าใช้ได้ทันทีจากทั่วโลก!

> 🛑 **การปิดระบบ:** ปิดหน้าต่างสีดำ (Command Prompt) หรือดับเบิลคลิกที่ไฟล์ **`STOP-SYSTEM.bat`**

## บทที่ 2: การเข้าใช้งานจากอุปกรณ์ต่างๆ

### 2.1 เข้าใช้งานจากคอมพิวเตอร์ในออฟฟิศ (Wi-Fi องค์กร)
- พิมพ์ URL: `http://<IP-เครื่องโฮสต์>:3000` (เช่น `http://192.168.1.50:3000`)

### 2.2 เข้าใช้งานจากสมาร์ตโฟน / แท็บเล็ต (เน็ตมือถือ 4G/5G หรืออยู่นอกออฟฟิศ)
- บนหน้าจอคอมพิวเตอร์ กดปุ่ม **"📱 มือถือ"**
- เลือกแท็บ **"🌐 นอกออฟฟิศ (4G/5G/WFH)"**
- ใช้กล้องมือถือสแกนภาพ **QR Code** หรือคัดลอกลิงก์ส่งทาง LINE ให้พนักงานเปิดเข้าใช้ได้ทันที!

### 2.3 โหมดจอแท็บเล็ตติดหน้าห้องประชุม (Room Display Kiosk)
- นำ iPad หรือแท็บเล็ตไปติดไว้หน้าห้องประชุม
- เปิดเบราว์เซอร์ไปที่: `http://<IP-เครื่องโฮสต์>:3000/kiosk.html`
- หน้าจอจะแสดงสถานะสีเขียว (ว่าง) / สีแดง (กำลังประชุม) พร้อมปุ่มจองด่วน 15, 30, 60 นาที

## บทที่ 3: คู่มือสำหรับพนักงานทั่วไป

### 3.1 การยืนยันตัวตนพนักงาน (Employee Verification)
- แม้จะเปิดให้เข้าจากภายนอกได้ แต่ **ระบบอนุญาตให้เฉพาะพนักงานที่มีสิทธิ์ของบริษัทเท่านั้นที่จองได้**
- กดปุ่ม **"เข้าสู่ระบบ"** มุมขวาบน แล้วกรอก **รหัสพนักงาน** (เช่น `EMP101`, `EMP102`) หรือพิมพ์ค้นหาชื่อของตนเอง
- เมื่อเข้าสู่ระบบแล้ว ชื่อผู้จองและแผนกจะถูกนำไปกรอกลงฟอร์มให้อัตโนมัติ

### 3.2 ขั้นตอนการจองห้องประชุม
1. กดปุ่มสีส้ม **"+ จองห้องประชุมใหม่"** (หรือกด "จองห้องนี้" จากการ์ดห้องประชุม)
2. เลือก **ห้องประชุม** ที่ต้องการใช้งาน (ห้อง A, B, C, D)
3. เลือก **วันที่** และ **เวลาเริ่มต้น - สิ้นสุด** (เช่น 13:00 - 14:30 น.)
4. กรอกหัวข้อการประชุม (ระบบจะสุ่มสร้างรหัส PIN 4 หลักให้อัตโนมัติสำหรับใช้ยกเลิกหรือแก้ไข)
5. กดปุ่ม **"ยืนยันการจองห้อง"**

> 🚨 **การป้องกันการจองซ้ำ:**  
> หากมีคนจองห้อง A เวลา 13.00 น. ไว้แล้ว คนอื่นที่พยายามเข้ามาจองห้องเดียวกันในเวลาดังกล่าว **จะไม่สามารถจองซ้ำได้เด็ดขาด** ระบบจะปฏิเสธทันทีพร้อมแจ้งเตือนชื่อคนจองเดิมและช่วงเวลาที่ติดจอง

### 3.3 การดูตารางการจอง
- ดูได้จากตาราง **Schedule Board** บนหน้าหลัก มีปุ่มสลับดู "วันนี้", "พรุ่งนี้", หรือ "ทั้งหมด"
- หรือกดปุ่ม "แถบไทม์ไลน์" เพื่อดูช่องว่างชั่วโมงต่อชั่วโมง (08:00 - 20:00 น.)

### 3.4 การยกเลิกการจอง
- ที่ตารางการจอง กดปุ่ม **"ยกเลิก"** ที่รายการของตนเอง
- กรอกรหัส PIN 4 หลักที่ได้รับตอนจอง

## บทที่ 4: คู่มือสำหรับผู้ดูแลระบบ (Admin Console)

เข้าสู่ระบบจัดการได้ที่: `/admin.html` หรือกดปุ่ม **"⚙️ Admin"**  
- **รหัส Master Admin PIN:** กำหนดผ่านตัวแปรสภาพแวดล้อม `ADMIN_PIN` หรือตั้งค่าในระบบ

### 4.1 กำหนดชื่อห้องประชุม (Manage Rooms)
- **เพิ่มห้อง:** กดปุ่ม `+ กำหนดห้องประชุมใหม่` ระบุรหัสห้อง, ชื่อห้องประชุม, ความจุคน, สถานที่, สีประจำห้อง, และอุปกรณ์ (Smart TV, ไมค์, Video Conf, ไวท์บอร์ด, Wi-Fi)
- **แก้ไข / ลบ:** แก้ไขชื่อห้อง หรือสั่งลบห้องที่ไม่ใช้งานได้ตลอดเวลา

### 4.2 กำหนดรายชื่อพนักงานที่มีสิทธิ์ใช้งาน (Manage Allowed Employees)
- **เพิ่มพนักงาน:** กดปุ่ม `+ เพิ่มพนักงานที่มีสิทธิ์ใช้งาน` ระบุรหัสพนักงาน, ชื่อ-นามสกุล, แผนก, ตำแหน่ง
- **ระงับสิทธิ์:** กดปุ่ม `⛔ ระงับ` พนักงานคนดังกล่าวจะไม่สามารถเข้าใช้งานหรือจองห้องได้
- **คืนสิทธิ์:** กดปุ่ม `✅ เปิดสิทธิ์` เพื่อให้พนักงานกลับมาจองห้องได้อีกครั้ง
- **แก้ไข / ลบ:** แก้ไขข้อมูลหรือลบออกจากระบบสิทธิ์ได้ทันที

### 4.3 การส่งออกรายงาน (Export Reports)
- กดปุ่ม **"📥 ส่งออก Excel"** เพื่อดาวน์โหลดไฟล์ `.csv` ภาษาไทย เปิดใน Microsoft Excel ได้ทันที

## บทที่ 5: ความปลอดภัยและการตั้งค่าโดเมนบริษัท (Custom Domain)

### 5.1 ความปลอดภัยของระบบรัน Local + Cloudflare Tunnel
- **ไม่มีการเปิด Port ใน Router:** ไม่ต้องทำ Port Forwarding จึงปลอดภัยจากการถูกเจาะระบบจากแฮกเกอร์บนอินเทอร์เน็ต
- **เข้ารหัสแบบ HTTPS:** ปลอดภัย มี Green Lock Certificate ตามมาตรฐานสากล
- **ข้อมูลทั้งหมดเก็บอยู่ที่เครื่องของคุณ:** ฐานข้อมูล SQLite อยู่บนเครื่องของคุณ 100% ไม่ถูกส่งไปเก็บไว้บน Cloud ของบุคคลภายนอก

### 5.2 การใช้โดเมนถาวรของบริษัท (เช่น meeting.mycompany.com)
หากบริษัทของคุณมีชื่อโดเมนอยู่แล้ว สามารถเชื่อมต่อ Cloudflare Tunnel กับโดเมนของบริษัทได้ฟรี:
1. สมัครใช้งาน Cloudflare Zero Trust (ฟรี)
2. สร้าง Tunnel แล้วนำ Token มารันด้วยคำสั่ง:
   ```cmd
   bin\cloudflared.exe tunnel run --token <YOUR_TOKEN>
   ```
3. พนักงานจะสามารถเข้าใช้งานผ่าน `https://meeting.mycompany.com` ได้ตลอดเวลาโดยชื่อ URL ไม่เปลี่ยน!
